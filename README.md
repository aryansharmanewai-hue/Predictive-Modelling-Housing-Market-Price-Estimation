# Predictive Modelling for Housing Market Price Estimation

## Project Overview
This project focuses on predicting housing market prices using machine learning techniques. It aims to estimate house prices based on available housing data and relevant property features.

The project includes a Jupyter Notebook for data analysis and model development, along with a Python application for interacting with the prediction system.

## Features
- Housing dataset analysis
- Data preprocessing and preparation
- Predictive modelling using machine learning
- House price estimation
- Python-based application interface

## Technologies Used
- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Jupyter Notebook

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/aryansharmanewai-hue/Predictive-Modelling-Housing-Market-Price-Estimation.git
```

### 2. Navigate to the project folder

```bash
cd Predictive-Modelling-Housing-Market-Price-Estimation
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

For Windows:

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
streamlit run house_price_app.py
```

## Project Files

- **house_price_app.py:** Python application for housing price prediction.
- **notebook.ipynb:** Jupyter Notebook containing project development and analysis.
- **requirements.txt:** List of required Python libraries.
